# Wat2Say — UI/UX Design Project

## Overview

Wat2Say is a collaborative UI/UX design project focused on creating a user-friendly digital experience for communication and interaction.

The project involved user research, identifying user needs, developing user flows, creating wireframes, and designing a high-fidelity mobile interface.

## My Role

This was a group project where I contributed to:

* User research
* Identifying user needs and pain points
* User flow development
* Wireframing
* UI design
* Prototype development
* Design iteration based on feedback

## Problem

Users can experience challenges when trying to communicate their needs clearly and efficiently to a larger audience. The goal of Wat2Say was to explore how a digital product could make this process simpler and more accessible.

## Design Process

### 1. User Research

We conducted research to understand users, their needs, behaviors, and pain points.

### 2. User Flows

Based on our research, we mapped the key user journeys and interactions.

### 3. Wireframes

We created low-fidelity wireframes to explore different layouts and interactions before moving into visual design.

### 4. UI Design

We developed high-fidelity mobile screens with a focus on usability, clarity, and consistency.

### 5. Prototype

The final designs were connected into an interactive prototype to demonstrate the intended user experience.
